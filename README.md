# 🎨 Blackboard Student App: UX Redesign & Heuristic Evaluation

## 📌 Project Overview
The goal of this project is to redesign key features of the "Blackboard Student" mobile app to improve usability and overall student experience[cite: 5]. The analysis targeted known issues within the platform, specifically difficult navigation, confusing assignment submissions, and a poor notification system[cite: 5]. 

## 🔍 Methodology & Research
* **Heuristic Evaluation:** Applied Nielsen’s 10 Usability Heuristics to uncover critical design flaws in the user interface[cite: 5]. This method allowed us to quickly identify issues such as a lack of system status visibility during loading, inconsistent terminology across courses, and missing error prevention warnings during file uploads[cite: 5].
* **Competitive Analysis:** Benchmarked the app against similar educational platforms like Classera and Madrasati[cite: 5]. We analyzed best practices in dashboard organization, automated assignment correction, and built-in notification systems to inform our redesign strategy[cite: 5].

## 💡 Design & Prototyping
* **Low-Fidelity Prototypes:** Redesigned the homepage and individual course pages to include a clean dashboard, simplified bottom navigation, and grouped notifications for clarity[cite: 5].
* **High-Fidelity Interactive Prototype:** Developed a fully clickable prototype using **Figma** focusing specifically on the "View Assignments" workflow[cite: 5]. The new interface clearly separates upcoming and submitted work, displaying status, due dates, and grades transparently[cite: 5].
